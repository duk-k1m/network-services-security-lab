# Network Analysis Tools

## Wireshark

- **Link:** [Wireshark Documentation](https://www.wireshark.org/docs/)
- **Type:** Official documentation
- **Level:** Beginner to Advanced
- **Why read:** The primary interactive tool in this hub for protocol dissection, stream analysis, display filters, and PCAP review.

## tshark

- **Link:** [tshark manual page](https://www.wireshark.org/docs/man-pages/tshark.html)
- **Type:** Official documentation
- **Level:** Intermediate
- **Why read:** Supports repeatable command-line extraction and analysis that can be documented in a lab report.

## tcpdump

- **Link:** [tcpdump manual page](https://www.tcpdump.org/manpages/tcpdump.1.html)
- **Type:** Official documentation
- **Level:** Intermediate
- **Why read:** Captures traffic efficiently near an endpoint or sensor and uses capture filters to reduce collection scope.

## Zeek

- **Link:** [Zeek Documentation](https://docs.zeek.org/en/current/)
- **Type:** Official documentation
- **Level:** Intermediate
- **Why read:** Turns observed network activity into structured logs that can be correlated with service and host evidence.

## Our Notes

- Capture filters decide what is collected; display filters decide what is shown after collection.
- Use synthetic credentials and sanitized captures for coursework artifacts.
- Network evidence should be time-synchronized with service and host logs before making a conclusion.
