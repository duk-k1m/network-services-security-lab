## Quick Facts

| Item | Value |
|---|---|
| Protocol | Internet Message Access Protocol |
| Default cleartext port | TCP 143 |
| Implicit TLS port | TCP 993 by convention |
| Primary model | Remote mailbox synchronization and management |

## Recommended Starting Resources

- [RFC 9051: IMAP4rev2](https://www.rfc-editor.org/rfc/rfc9051) - current protocol specification.
- [RFC 2595: TLS for POP3 and IMAP](https://www.rfc-editor.org/rfc/rfc2595) - STARTTLS context.
- [RFC 8314: Cleartext Considered Obsolete](https://www.rfc-editor.org/rfc/rfc8314) - secure access direction.
- [Dovecot Documentation](https://doc.dovecot.org/main/) - official implementation documentation.
