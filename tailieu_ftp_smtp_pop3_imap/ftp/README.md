## Quick Facts

| Item | Value |
|---|---|
| Protocol | File Transfer Protocol |
| Default control port | TCP 21 |
| Data channels | Separate active or passive data connection |
| Encryption | Not provided by FTP itself; FTPS adds TLS |

## Recommended Starting Resources

- [RFC 959: File Transfer Protocol](https://www.rfc-editor.org/rfc/rfc959) - primary protocol specification.
- [RFC 4217: Securing FTP with TLS](https://www.rfc-editor.org/rfc/rfc4217) - the standard FTPS reference.
- [RFC 2577: FTP Security Considerations](https://www.rfc-editor.org/rfc/rfc2577) - concise threat and deployment guidance.
- [Wireshark Documentation](https://www.wireshark.org/docs/) - packet-analysis workflow for FTP sessions.
