# Network Services Security Research Hub

Use this page as the central navigation layer. It intentionally keeps detail in the focused documents so that members can go directly to the material needed for their assigned work.

## Quick Start

1. Read the [team assignment](./phan-cong-tan-cong-phong-thu-dieu-tra.md) and select the service or lab track.
2. Review the [fundamentals](./fundamentals/README.md) needed to understand traffic, encryption, and evidence.
3. Follow one service through Overview, Attack, Detection, Defense, and Forensics.
4. Use [labs](./references/labs.md) and [datasets](./references/datasets-pcap.md) only in an authorized environment.
