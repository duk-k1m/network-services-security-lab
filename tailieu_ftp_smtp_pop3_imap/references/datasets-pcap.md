# PCAP and Datasets

Select material based on its license, privacy constraints, collection context, and relevance to the question being studied. Do not upload PCAPs that contain real credentials or private messages.

## Wireshark Sample Captures

- **Link:** [Wireshark Sample Captures](https://wiki.wireshark.org/SampleCaptures)
- **Type:** PCAP
- **Relevant to:** General protocol analysis
- **Useful for:** Detection and investigation practice with known capture artifacts.

## Stratosphere IPS Datasets

- **Link:** [Stratosphere IPS Datasets](https://www.stratosphereips.org/datasets-overview)
- **Type:** Network traffic and security datasets
- **Relevant to:** General network detection
- **Useful for:** Network-behavior research and detection experiments; inspect dataset documentation before selecting a subset.

## CIC-IDS2017

- **Link:** [CIC-IDS2017 Dataset](https://www.unb.ca/cic/datasets/ids-2017.html)
- **Type:** Traffic and IDS dataset
- **Relevant to:** General IDS research
- **Useful for:** Evaluating detection workflows and discussing data-label limitations.

## Digital Corpora

- **Link:** [Digital Corpora](https://digitalcorpora.org/)
- **Type:** Digital-forensics corpus
- **Relevant to:** Email and host forensics
- **Useful for:** Finding research and education artifacts while honoring their stated terms.

## NIST CFReDS

- **Link:** [NIST Computer Forensic Reference Data Sets](https://cfreds.nist.gov/)
- **Type:** DFIR reference dataset catalog
- **Relevant to:** General forensics
- **Useful for:** Reference data and reproducible forensic-method testing.

## Our Notes

- A dataset label is evidence about the dataset's construction, not automatic ground truth for a new environment.
- Preserve original filenames, hashes, source URLs, collection dates, and any data-use restrictions in a lab notebook.
- PCAP content can include credentials and message bodies; classify it before sharing.
