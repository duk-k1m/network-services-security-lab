# Phan Cong: Attack, Defense, and Investigation

The original [interactive assignment page](./phan-cong-tan-cong-phong-thu-dieu-tra.html) is preserved unchanged and remains the visual navigation page for the team.

## Current Assignment

| Member | Service / Track | Lab narrative |
|---|---|---|
| Member 1 | FTP | Cleartext credential and file-transfer exposure, encryption migration, PCAP investigation |
| Member 2 | FTPS | TLS configuration weakness, stronger transport settings, TLS-failure log review |
| Member 3 | SFTP / SSH | Authentication anomaly, key-based hardening, SSH authentication-log investigation |
| Member 4 | SMTP | Relay and mail-flow security, access restrictions, mail-queue and log correlation |
| Member 4 | POP3 / IMAP | Mail access exposure, TLS enforcement, mailbox-activity investigation |

The agreed demonstration workflow is: baseline, controlled lab event, defensive change, retest, then forensic analysis. Preserve only synthetic credentials and data in screenshots, logs, and PCAPs.
